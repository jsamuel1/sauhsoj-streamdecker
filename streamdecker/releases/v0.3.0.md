## Streamdecker v0.3.0

### New Features
- **Launch / Focus targets** — configurable keys that launch or focus one of four
  targets: **kiro-cli**, **Claude Code** (terminal), **Amazon Quick**, and
  **Claude** (desktop apps). Launch starts a new session (a new terminal tab, or
  ⌘N for the GUI apps); Focus brings the target to the front. Terminal targets take
  an optional project folder. Available as Elgato plugin actions (Launch Target /
  Focus Target) and as standalone button actions.
- **House-style target icons** — purple-ghost icons themed per product (launch =
  rocket, focus = viewfinder).
- **Config-driven standalone** — the standalone app now renders and dispatches its
  Stream Deck keys from `config.buttons`. Configure any key — action, target,
  folder, icon, label — from the emulator's **Settings → Buttons** editor (or by
  editing `config.json`).

### Changes
- Reconciled the Trust action id to `kiro.trust` across the app.
- Emulator renders button labels from config; mini layout key indices aligned to
  positions 0–5.
- Menubar build degrades to the available architecture instead of failing when the
  x86_64 Swift toolchain is absent.

### Requirements
- macOS 12+ (Apple Silicon supported natively)
- For cmux terminal targets: cmux with Socket Control Mode = **Automation**, `cmux`
  on `PATH`
- For GUI-app new-session (⌘N): macOS Accessibility permission for the controlling
  app
