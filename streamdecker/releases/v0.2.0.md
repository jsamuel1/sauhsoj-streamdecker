## Streamdecker v0.2.0

### New Features
- **cmux terminal backend** — drive [cmux](https://github.com/manaflow-ai/cmux)
  in addition to iTerm/Terminal/Warp/WezTerm. Set `terminal.app: "cmux"` (or rely
  on `auto`, which prefers a running cmux). Uses the `cmux` CLI over its control
  socket; no macOS Automation permission needed. Alert/attention detection uses
  cmux's native notifications.
- **Native Swift menubar** — replaced the menubar helper with a universal
  (arm64 + x86_64) `NSStatusItem` app, so the standalone runs natively on Apple
  Silicon without Rosetta. Menubar failures are now non-fatal.

### Changes
- Backends refactored behind a single `TerminalBackend` interface shared by the
  standalone app and the Elgato plugin.
- CI: added a Test workflow (typecheck + unit tests); bumped all GitHub Actions to
  their latest major versions.
- Strict TypeScript typecheck fixes across the standalone app.

### Requirements
- macOS 12+ (Apple Silicon supported natively)
- For cmux mode: cmux installed with Socket Control Mode set to **Automation**,
  and the `cmux` CLI on `PATH`
